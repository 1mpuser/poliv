# Поливалка — вёрстка

Статичный HTML/CSS + vanilla JS, без сборки. Открывается прямо из файла.

| Файл | Экран |
|---|---|
| `index.html` | Дашборд: карточки растений, быстрые действия |
| `plant.html` | Детали растения: статусы, график за 8 недель, история |
| `settings.html` | Настройки: интервалы (степперы), тумблеры, тема |
| `styles.css` | Токены (цвета, радиусы, шрифты), светлая и тёмная тема |
| `app.js` | Поведение UI; все запросы к серверу — в объекте `api` в начале файла |

## Контракт разметки

- **Растение:** любой контейнер с `data-plant-id="…"`, внутри — плитки и кнопки.
- **Статус-плитка:** `.stat[data-stat="water|feed|lamp"][data-status="ok|soon|late"]`.
  Число — в `[data-value]`, короткая метка — в `[data-flag]` (`скоро` / `пора`; для лампы `мало`).
  Цвет плитки задаёт только `data-status`.
- **Быстрое действие:** `.action[data-action="water|feed|lamp"]`. Лампа — переключатель с `aria-pressed`.
  После нажатия UI сразу обновляет плитку, вызывает `api.logEvent(plantId, type)`
  (`water`, `feed`, `lamp_on`, `lamp_off`) и показывает тост «Отменить», который вызывает `api.deleteEvent(id)`.
- **Сетка карточек:** `.plant-grid` — `auto-fill`, от 1 колонки на телефоне до 3–4 на десктопе.
  Добавлять карточки можно без изменений в CSS.
- **Таймлайн:** `.tl-day` — заголовок дня, `.tl-item[data-type="water|feed|lamp|repot"]`, иконка `#i-{type}`.
- **График:** `.chart__bars` с `--max` (шкала), в каждой неделе `.bar__seg` с `--n` (количество событий).
- **Степпер:** `.stepper[data-min][data-max][data-step][data-units="день,дня,дней"]`,
  значение — в скрытом `<input name="…">`. Для часов — `data-format="time"`.
- **Тумблер:** `<input type="checkbox" class="switch" role="switch">`;
  `data-controls="id1 id2"` отключает зависимые поля.

Правила статусов (когда `soon`, когда `late`) вычисляет бэкенд.
Порог для «скоро» — настройка `notify_days_ahead`.
