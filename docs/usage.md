# Как пользоваться

Руководство для владельца и тех, кому выданы учётки. Адрес: https://polivalochka.ru

## Вход

Почта и пароль, которые выдал админ. Регистрации нет. Забыли пароль — админ выдаёт новый во
вкладке «Админка» (или `reset-password`, см. [accounts.md](accounts.md)).

## Дашборд

Карточка на каждое растение:

- **Плитки**: дней с полива · дней до следующей подкормки (и какое удобрение по очереди) · **свет**
  сегодня против нормы растения. Зелёный — в норме, жёлтый — скоро/маловато, красный — пора/мало.
- **Подсказка по свету** под плитками: «Не хватает 4,7 ч — лампа 18:23–23:02» — когда включить лампу,
  чтобы добрать норму. «…и до полуночи не хватит» — даже вечерней лампы мало.
- **Пересадка**: дата последней и когда проверить горшок.
- **Кнопки**: «Полить», «Подкормить» (удобрение по очереди уже выбрано, можно поменять и выбрать
  под корень / по листу), «Лампа». После нажатия 5 секунд есть «Отменить».
- **Лампы** над карточками — чипы ламп учётки, которые можно включить/выключить кнопкой (и у каждой кнопка «Лампа»).

Кнопка «Лампа» переключает то, что горит сейчас: если лампа горит по расписанию или досветкой — нажатие
значит «выключил раньше», если не горит — «включил вручную». Растение без лампы — кнопка неактивна.

## Свет и лампы — настроить один раз

1. **«Настройки» → «Свет» → «Город»**: ввести город (например, «Мытищи») → «Найти» → выбрать из списка.
   Сразу покажутся восход, закат, световой день и часы солнца сегодня. Это нужно и для режима «Авто».
2. **«Настройки» → «Лампы»** → «Добавить лампу»: имя, розетка (или «без розетки» — только учёт), режим:
   - **«Авто»** — лампа сама досвечивает до нормы самого требовательного растения: половину нехватки утром
     до рассвета, остаток вечером после заката. Нужны город (см. п. 1) и умная розетка (см. ниже).
     Дополнительно — «утром не раньше» и «вечером не позже».
   - **«По расписанию»** — интервалы так же, как стоят в розетке, например 07:00–10:00 и 17:00–21:00.
   - **«Вручную»** — только кнопкой.
   Отметьте растения под лампой.
3. **«Настройки» → растение → «Норма света»**: сколько часов света всего в день (солнце + лампа),
   например 13–14. Сохраняется кнопкой «Сохранить» внизу. Там же — «Под какой лампой стоит».
4. **«Настройки» → «Свет» → «Умный дом Яндекса»**: вставить токен (см. ниже).

### Умная розетка (Smart Life → Алиса → Поливалка)

1. Smart Life: добавить розетку (Wi-Fi 2,4 ГГц, зажать кнопку ~5 с), назвать, например, «Лампа цитрусы».
   Подстраховка: в самой розетке расписание «выключить в 23:30 ежедневно», других программ не ставить.
2. Дом с Алисой: «+» → «Устройство умного дома» → Smart Life → привязать аккаунт → обновить список.
3. Токен: oauth.yandex.ru/client/new → «Веб-сервисы», Redirect URI `https://oauth.yandex.ru/verification_code`,
   права «Умный дом»: просмотр и управление → создать. Открыть
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=<ClientID>` → «Разрешить» → скопировать токен.
   Токен живёт около года; истёк — в «Настройки → Свет» будет «недействителен», вставить новый.
4. Поливалка: «Настройки → Свет → Умный дом Яндекса» — вставить токен, «Проверить».
   «Настройки → Лампы» — лампа, розетка из списка, режим «Авто», растения.
   Выключили лампу через Алису — Поливалка не включит её назад до следующего переключения по плану.

Как считается:

- Солнце — часы **прямого солнца с учётом облачности** в выбранном городе (Open-Meteo). В пасмурный
  день их мало, поэтому лампе нужно работать дольше. Для примера, Мытищи 24.09: день 12,1 ч, солнца 5,5 ч;
  21.12: день 7 ч, солнца 0.
- Лампа — часы её сессий (расписание, ручные включения, досветка) за период, когда растение стояло под ней.
  Пересечения не считаются дважды.
- На подоконнике света меньше, чем на улице — это ориентир, норму можно ставить с запасом.
- Интервал через полночь — двумя строками: 22:00–23:59 и 00:00–02:00.

## Экран растения

Нажать на карточку. Там: плитки с подробностями («солнце 5,5 + лампа 1,9 из 12»), подсказка по свету,
«Записать пересадку», графики за 8 недель (поливы и подкормки; свет — солнце и лампа), история всех
событий с фильтром по типу и датам.

## Настройки

- **Растение**: название, вид, где стоит, горшок, заметки; полив раз в N дней, норма света, подкормка
  вкл/выкл, проверка горшка раз в N месяцев; «Под какой лампой стоит»; удалить растение.
- **Сезон**: активный рост / покой — от него зависит интервал подкормки у удобрения.
- **Свет**: город, токен Яндекса.
- **Лампы**: список ламп — имя, режим, розетка, растения; добавить, изменить, удалить.
- **Напоминания**: за сколько дней статус становится жёлтым.
- **Удобрения**: название, NPK, дозы под корень и по листу, интервалы для роста и покоя.
- **Оформление**: тема. **Аккаунт**: сменить пароль, выйти.

Новое растение — «Добавить растение» на дашборде.

## Админка (только владелец)

Создать учётку (пароль генерируется, показывается один раз — «Скопировать» и отправить), выдать новый
пароль, заблокировать, удалить. Подробно — [accounts.md](accounts.md).
