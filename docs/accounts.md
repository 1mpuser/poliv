# Учётки

Самостоятельной регистрации нет. Логин — почта. У каждой учётки свои растения, удобрения,
настройки и общая лампа; друг друга учётки не видят.

## Первый вход

После первого деплоя на чистую базу (или после миграции 0002) данные принадлежат заглушке
`owner@localhost.invalid`, войти под ней нельзя. Дать ей почту, пароль и права админа:

```bash
ssh root@213.108.23.47 'cd /opt/poliv && docker compose -f docker-compose.yml -f docker-compose.server.yml \
  exec -T backend python -m app.cli set-owner --email alex022003@mail.ru'
```

Пароль печатается **один раз** — сохранить. Из сессии Claude запускать через `! …`: классификатор
Claude Code не даёт агенту читать пароли, вывод должен идти сразу пользователю.

## Админка (вкладка «Админка», только для админа)

- **Создать учётку**: почта + пароль. Пароль сразу сгенерирован (16 символов, без похожих `0/O`, `1/l/I`),
  можно перегенерировать или ввести свой (8–128 символов). После создания почта и пароль показываются
  один раз; «Скопировать» кладёт в буфер готовый текст со ссылкой на сайт — его можно сразу отправить.
- **Новый пароль** — генерируется и показывается один раз; старый перестаёт работать на всех устройствах.
- **Заблокировать / Разблокировать** — заблокированная учётка сразу разлогинивается и не может войти
  (на входе ответ такой же, как на неверный пароль). Данные остаются.
- **Удалить** — со всеми растениями и историей, подтверждение вводом почты. Без отмены (только из бэкапа БД).
- Свою учётку заблокировать или удалить нельзя; свой пароль — в «Настройках» → «Аккаунт».
- Новая учётка начинается пустой, с удобрениями Lomonosoff и Bona Forte (NPK и дозы — заполнить в настройках).

Для не-админа `/api/admin/*` отвечает 404, вкладки нет, `/admin` перенаправляет на главную.

## Команды на сервере

Префикс для всех: `cd /opt/poliv && docker compose -f docker-compose.yml -f docker-compose.server.yml exec -T backend`

| Команда | Что делает |
|---|---|
| `python -m app.cli set-owner --email X` | Заглушке владельца (или существующей учётке X) — почта X, новый пароль, админ, разблокировка |
| `python -m app.cli create-user --email X [--admin]` | Новая учётка |
| `python -m app.cli reset-password --email X` | Новый пароль (если админ забыл свой) |
| `python -m app.cli make-admin --email X` | Сделать админом (через интерфейс назначить нельзя) |

Пароль генерируется, если не передан `--password`. Локально — то же без `-f … server.yml`.

## Сам себе

«Настройки» → «Аккаунт»: почта, «Сменить пароль» (нужен текущий; другие устройства разлогиниваются,
текущее остаётся в системе), «Выйти».
