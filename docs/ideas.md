## Умная розетка: приложение само включает лампу

Сейчас розетка программируемая: расписание задаётся в розетке и дублируется в приложении,
которое по нему только считает часы. С умной розеткой (Tuya/Smart Life, Яндекс, Xiaomi/Mi Home,
Sonoff/eWeLink, Shelly) можно:

- включать и выключать лампу по расписанию из приложения — одно расписание вместо двух;
- режим «добить до нормы»: каждый день после заката включать лампу ровно на нехватку
  (`light.deficit_hours` из сводки уже считается, окно — `suggestion_start/end`);
- кнопка «Лампа» в приложении физически щёлкает розеткой;
- для некоторых розеток — фактическое потребление как подтверждение, что лампа горела.

Как встраивать:
- у лампы (своей/общей) — поле «устройство» (тип интеграции + id + секрет в зашифрованном виде);
- фоновая задача (`services/light.sync_all`) уже крутится раз в 30 минут — для точного включения
  нужен шаг чаще (раз в минуту) или планирование задач на время начала/конца интервала;
- самые простые API локально: Shelly (HTTP в локальной сети — но сервер не в квартире), Tuya Cloud
  (облако, нужен аккаунт разработчика), Яндекс Умный дом (OAuth). Для VPS в другой сети нужен облачный API.

## Прочее

- Поправка на окно у растения (север/юг, расстояние от стекла) — множитель к солнечным часам.
- Интервалы расписания через полночь одной строкой (сейчас — двумя).
- Push-уведомления «пора полить» (в макете было время уведомлений).
